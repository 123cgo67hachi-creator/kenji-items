## 0. この台本の前提（設計思想）

これまでの「1分で完結するルーティンを回す」型は、**1,000〜3,000円の即決商品の売り方**。
6万〜10万円のポータブル電源は、心理として次の順で動く。

```
①「何これ」 → ②「自分に関係ある」 → ③「うちの場合いくら使える？」
→ ④「他と比べてどう？」 → ⑤「損しない？」 → ⑥「今日の値段なら」
```

**この⑥に着地させるのに必要な滞在は10〜20分。**
だから台本は「1分の繰り返し」ではなく、**15〜20分で1周するブロックのループ**にする。
ただし新規流入は常に入るので、**各ブロックの頭20秒だけは毎回リセット情報を入れる**（後述 B0）。

### 正直に言うべき弱点（言った方が売れる）

1. **シガーソケット（12V）とDC5521がない。** AC×3とUSB×3のみ。上位のDELTA 3にはある。
   → 車載12V冷蔵庫を直結したい人には向かない。**この人は上位機種を案内する。**
2. **拡張バッテリー非対応。** 後から容量を足せない。長期停電・オール電化フル対応は上位のPlus。
3. **12.1kgは「軽い」わけではない。** 女性が階段で持ち運ぶのはしんどい。ただし縦型スリムで置き場所は取らない。
4. **エアコンは動かない。**

> ⚠️ 配信前の最終確認推奨項目：瞬間最大W（サージ）の公式表記／Storm Guard（悪天候12時間前に自動満充電するアプリ機能）のClassic対応可否／当日のクーポン後価格・在庫数。公式ページで数字を確定させてから読むこと。

## 2. 口コミ深掘り：「なぜ・何のために買ったか」

100人規模の調査では **92%が「買って後悔していない」**。一方で後悔の中身も明確に偏っている。
ここが台本の骨。

### 買った理由 5類型（多い順）

**① 防災・停電対策（最多）**
- 「台風で2日停電して、冷蔵庫の中身を全部捨てた」
- 「スマホの充電が切れて、家族の安否も避難情報も取れなくなった」
- 「災害が起きてから買いに走っても、もう店に在庫がなかった」
- 買った後の言葉は**「安心を買った」「精神的に全然違う」**が圧倒的に多い
→ **キーワードは「保険」。使わないのが正解の買い物、という語り。**

**② 車中泊・キャンプ**
- 「バンで車中泊。電子レンジを使いたかった」
- 「冬に電気毛布を使いたい。これがあるかないかで寝られるかが決まる」
- 「ペットと孫を連れて車中泊。コンパクトで充電が速くて静かなのが良かった」
→ **具体家電名（電気毛布・電子レンジ・扇風機）が刺さる。**

**③ 在宅ワーク・UPS用途（EcoFlowで特に多い）**
- 「停電でも仕事が止まらない」
- 「ルーター・NAS・モニターを挟んでおけば瞬停でも落ちない」
- 「冷蔵庫とWi-Fiを同時に守れる」
→ **10ms切替は競合より速い。ここは技術的な決め手になる。**

**④ 家族の事情（不安がいちばん濃い層）**
- 赤ちゃん：停電するとミルクのお湯が沸かせない
- 高齢の親：実家に1台置いておきたい
- ペット：夏の停電で人より先に弱る
- 医療機器（CPAP）：電源が止まると眠れない
→ **この層は価格で悩まない。「守れる／守れない」で決める。**

**⑤ 電気代・その他**
- 夜間に充電して昼に使う
- 屋外DIY・釣り・イベント・撮影

### 「後悔した人」の理由 ＝ ライブで先回りして潰す論点

| 後悔ポイント | この機種の回答 |
|---|---|
| 容量が足りなかった | 用途を先に確定させる。「何を何時間」を一緒に決める |
| 重くて動かせない | 12.1kg・縦型スリム・ハンドル付き。家置き前提なら問題なし |
| 結局使わなかった | 普段使い導線（在宅ワークのUPS・車中泊）をセットで提案 |
| 充電に何時間もかかる | **60分でフル。これが最大の差別化** |
| バッテリーがすぐヘタる | **4,000回・80%維持・保証5年** |
| ファンの音がうるさい | 600W以下で約30dB |
| 付属品・ケーブルが別売りだった | セット内容を画面で明示する |

**→「後悔ポイント7つのうち5つを、この機種は構造的に潰している」。これは強い口説き文句。**

### 市場の追い風（数字で言うと効く）

- 南海トラフ巨大地震の想定：**発災直後に約9割が停電、3日後でも約6割が停電のまま**
- 国内ポータブル電源市場は年平均8.34%成長（2026-2035）
→ **「3日」を基準単位にして話す。**

## 6. 言ってはいけないこと（リスク管理）

- 「地震が来ます」「◯月に来ます」など**災害の断定的予測**
- 「これがあれば絶対に安心／命が助かります」など**効果の断定**
- 医療機器（CPAP等）について「**必ず動きます／医療機器として保証します**」→「使えている方が多いですが、機器の消費電力をご確認ください」に留める
- 実測していない稼働時間を「実測」と言う → **「目安です」を必ず添える**
- 他社製品の**名指しでの品質否定**（「あそこは壊れる」等）→ 比較は**数字の差**だけで語る
- **PR表記**（広告/PR）を配信中・概要に出す

## 7. 配信オペレーション

- **1周20分 × 3〜5周**。周回ごとに B1 の情景を差し替える（台風 / 夏の停電 / 車中泊 / 在宅ワーク）と飽きない
- 各ブロック冒頭で **B0（20秒リセット）** は絶対に省略しない
- **「かごに入れて、違ったら外して」** を1周に2回以上
- 販売の山は **2周目後半〜3周目**。1周目で売れなくても正常
- 実演（B3）は**毎周やる**。動いてる絵が一番強い
- コメントで来た質問は、**答えたあと必ずB0に戻す**（新規が入っているため）
